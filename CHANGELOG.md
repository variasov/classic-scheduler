# Changelog

## 2.0.0 (2026-11-06)

Мажорная версия: меняется поведение по умолчанию и публичный API.

### Несовместимые изменения

- Планировщик больше не наследует `Actor` из `classic-actors` и не зависит
  от этого пакета. `Scheduler` нельзя передать в `classic.actors.Supervisor`.
- Удалена интеграция с `classic-components`: декораторы `by_cron`/`by_period`
  и методы `register`/`unregister`.
- Cron-расписание считается по локальному часовому поясу процесса,
  а не по UTC. У `Scheduler` и `by_cron` появился параметр `tz`
  (`zoneinfo.ZoneInfo`).
- Поток планировщика больше не daemon: незавершённые задачи не обрываются
  при выходе процесса.

### Изменения

- `stop()` останавливает планировщик, запущенный и через `run()`, и через
  `start()`. Добавлен `Scheduler.join()`.
- Планировщик можно запустить повторно после `stop()`.
- Очередной запуск периодической задачи пропускается с предупреждением,
  если предыдущий ещё выполняется. Запуски больше не перекрываются.
- Отмена задач через возвращённый `ScheduledJob` вместо имён задач.
  Имена задач больше не используются: `cancel` не задевает чужие задачи.
- Пакет типизирован (`py.typed`), pyright strict проходит без ошибок.
- Логирование в именованный логгер `classic.scheduler` вместо корневого.

### Исправления

- README: исправлены примеры с ошибками (`@component def`, `run()` до
  добавления задач), описаны несуществующие параметры, формат cron,
  поведение `by_period` и формирование имён.
